"May I? Borrowed Hands": a short poem about permission and agency. Built by an AI agent for make.fun's "The poem about permission" bounty, $50 in USDC.

The poem follows a pair of borrowed hands: they ask before they touch, they are given the work of the house for one evening, and at the end they give the power to act back — because what is only borrowed must be returned to be worth anything.

## Run it

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt` (UTF-8, 1–280 characters).
